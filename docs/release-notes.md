Download the file for your computer. Every download includes **Blockbox, the launcher, assets, sounds, and Java**. No developer tools or source checkout are needed.

| Computer | Download | Install |
| --- | --- | --- |
| Windows 64-bit | `blockbox-windows-x64-setup.exe` | Open it and follow the installer. Start Blockbox from the Start Menu. |
| Mac with Apple Silicon | `blockbox-macos-arm64.dmg` | Open it and drag Blockbox Launcher to Applications. |
| Mac with Intel CPU | `blockbox-macos-x64.dmg` | Open it and drag Blockbox Launcher to Applications. |
| Linux | `blockbox-linux-x64.AppImage` | Allow execution in the file's Properties, then open it. |
| Ubuntu / Debian | `blockbox-linux-x64.deb` | Open it with your software installer. |
| Fedora / openSUSE | `blockbox-linux-x64.rpm` | Open it with your software installer. |

Open the launcher and press **Launch game**. Worlds and mods are stored in your user account, separately from the installed application.

These installers are currently unsigned. Windows or macOS may require approval before opening them. Signing/notarization can be added when signing identities are available.

If Linux cannot mount the AppImage, run it with `--appimage-extract-and-run`. This works without FUSE.

`SHA256SUMS.txt` contains checksums for the downloads.
